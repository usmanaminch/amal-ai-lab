# Book Selector AI v1 — Real AI Upgrade

This is the actual website + backend code.

## What it does

- Optional book/photo upload
- Choose reading mood, genre, length, reader level
- AI recommends 5 books
- Each pick includes title, author, why it fits, reading vibe, try-if-you-like note, and generated reading vibe image

## Uses existing setup

No new API key needed. It uses the same Vercel `OPENAI_API_KEY`.
