# Decor Helper AI v1 — Real AI Upgrade

This is the actual website + backend code.

## What it does

- Upload room/photo
- Choose room type, style, budget, colors, what to keep, what to avoid
- AI gives 3-sentence decor advice
- AI creates 4 makeover ideas
- Each idea includes a generated room preview image

## Uses existing setup

No new API key needed. It uses the same Vercel `OPENAI_API_KEY`.
