# HabitFlow PWA Installable App

This update makes HabitFlow installable like an app from the browser.

## What it adds

```text
projects/habitflow-app/manifest.json
projects/habitflow-app/service-worker.js
projects/habitflow-app/icons/icon-192.png
projects/habitflow-app/icons/icon-512.png
projects/habitflow-app/icons/maskable-512.png
scripts/install-habitflow-pwa.py
README_HABITFLOW_PWA.md
```

## Important

This update is designed to keep the HabitFlow design exactly as-is.
It only adds installable app/PWA features.

## How to install after publishing

On iPhone/iPad:
1. Open HabitFlow in Safari
2. Tap Share
3. Tap Add to Home Screen

On Chrome desktop:
1. Open HabitFlow
2. Click the install icon in the address bar if it appears
3. Or open Chrome menu and choose Install HabitFlow
