# Day 27 v4 — HabitFlow Focused Tabs

This version simplifies the professional habit app into three real app tabs.

## New tabs

- Dashboard: completion, done today, longest streak, next reminder
- Habits: add habit form and habit list
- Insights: best category, open tasks, trainer note

## What changed

- Removed unnecessary section-style navigation
- Gave Dashboard metrics their own tab
- Gave Insights their own tab
- Kept Habits as the working area for adding and managing habits
- Still supports localStorage, reminders, filters, and browser notifications
