# Day 27 v2 — Habit Reminder Trainer App

This is the upgraded all-ages version of the habit trainer.

## What changed

- Renamed from kids-only to all-ages Habit Reminder Trainer App
- Adds reminder times
- Adds browser notifications
- Adds examples like water plants, time to pray, drink water, read, move your body, and study
- Still saves habits using localStorage

## Important notification note

Browser notifications work after the user clicks Enable Notifications.
The app checks reminder times while the page/browser is open.
True closed-app mobile push notifications require a more advanced service-worker push setup.
