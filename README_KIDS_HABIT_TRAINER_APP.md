# Day 27 — Kids Habit Trainer App

This is a real app because it stores data in the browser with `localStorage`.

## Features

- Add custom habits
- Add quick-start habits
- Mark habits done for today
- Track today's completion percentage
- Get a trainer message
- Track streaks
- Earn badges
- Reset today's checks
- Clear all habits
- Data saves after refresh
