# Snack Helper AI v1 — Real AI Upgrade

This is the actual website + backend code.

## What it does

- Optional pantry/fridge/snack photo upload
- Choose snack mood, time, snack type, sweetness, ingredients, and things to avoid
- AI creates 4 easy snack ideas
- Each snack includes ingredients, steps, why it fits, adult help note, and generated snack preview image

## Uses existing setup

No new API key needed. It uses the same Vercel `OPENAI_API_KEY`.
